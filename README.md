# 給食タイム

教室で毎日使える、視覚的で楽しい給食時間タイマーです。

## モード
- 🍚 準備：給食準備をカウントアップし、準備時間だけlocalStorageへ記録
- 🍎 もぐもぐ：5分カウントダウン。30秒ごとにりんごが1つ減る
- 🕐 時計：現在時刻を大きく表示
- 🪥 はみがき：3分カウントダウン

## 共通資産
UIはedu-kitのデザイン思想をベースにし、ナビキャラはnavi-character-の「なみ」を利用しています。

## データ
ログインやサーバー保存は不要です。準備記録は使用中のブラウザのlocalStorageに保存します。保存するのは日付、開始時刻、終了時刻、準備時間です。

## トップ画像
`assets/eating-top.jpg` は給食の教室イメージとしてトップに使用しています。

## GitHub Pages
`main` ブランチをGitHub Pagesの公開元に設定すれば、そのまま静的サイトとして公開できます。
